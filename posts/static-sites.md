# Getting Started with Static Sites

Static sites are made of plain files — HTML, CSS, and JavaScript — that get served
exactly as they are, with no server-side processing.

## Basic ingredients

1. An `index.html` page that lists your content
2. A `style.css` file for design
3. Content files (in this case, Markdown for blog posts)
4. A tiny script to glue it together

That's it. No database, no server code, no complicated setup.

```js
console.log("Simple is good.");
```
